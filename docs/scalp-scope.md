# 두피 관찰용으로 쓰기

이 카메라를 두피 진단기처럼 쓰려면 무엇이 필요한지 정리했습니다.

> 관찰·기록 용도입니다. 탈모나 두피 질환의 진단은 의료 행위이니, 이 장비의
> 화면만으로 판단하지 마시고 필요하면 전문의 진료를 받으세요.

## "200배"가 실제로 뜻하는 것

시중 두피 진단기의 배율 표기는 **모니터에 띄웠을 때 기준**입니다. 같은 영상도
6인치 폰에서는 50배, 24인치 모니터에서는 200배가 됩니다. 그래서 배율보다
**시야 폭(한 화면에 담기는 실제 크기)** 으로 잡는 게 정확합니다.

| 표기 | 실제 시야 폭 | 이 센서에 필요한 광학 배율 |
|---|---|---|
| 약 50배 | 8~10mm | 0.5배 |
| 약 200배 | 2~3mm | **약 2배** |

SC3336 은 가로 2304픽셀이므로, 시야 폭 2mm 면 **픽셀당 0.87μm** 입니다.

- 머리카락 굵기 70μm → 약 80픽셀
- 모공 간격 0.5~1mm → 화면의 1/4 ~ 1/2

모공 위치, 모공당 모발 개수, 모발 굵기 차이, 각질 상태를 보기에 충분합니다.
**센서 성능은 넉넉하고, 결과를 가르는 건 광학·조명·거리 고정입니다.**

## 필요한 것 네 가지

### 1. 접사 — 돈 안 드는 방법부터

M12 렌즈를 **몇 바퀴 풀면** 센서와의 거리가 멀어지면서 최소 초점 거리가 짧아집니다.
이것만으로 접사가 됩니다. 한 바퀴씩 돌려가며 화면을 보고 원하는 크기를 찾으세요.

더 필요하면 순서대로:

- M12 익스텐션 링(스페이서) — 수천 원, 렌즈와 보드 사이에 끼웁니다
- M12 접사 전용 렌즈

### 2. 링 조명 — 없으면 아무것도 안 보입니다

두피는 머리카락 그늘 아래 있어서 일반 조명으로는 어둡고 그림자가 집니다.
렌즈 주위를 둘러싸는 **백색 LED 링**이 필요합니다. 시중 진단기 프로브 끝이
전부 이렇게 생긴 이유입니다.

- 확산판(유산지, 반투명 아크릴)을 씌우면 반사가 줄어 훨씬 보기 좋습니다
- 편광 필름을 렌즈와 조명에 교차로 붙이면 피지 번들거림이 줄어듭니다

### 3. 거리 고정 경통 — 실용성을 가르는 부분

접사에서는 **심도가 1mm도 되지 않습니다.** 손으로 들고 초점을 맞추는 건
사실상 불가능합니다.

투명 아크릴 통이나 3D 프린트 스페이서로 **렌즈에서 두피까지의 거리를 고정**하고,
두피에 갖다 대면 항상 초점이 맞도록 만드세요. 이게 있고 없고가 쓸 만한 장비와
못 쓰는 장비를 가릅니다.

만드는 순서:

1. 렌즈를 조절해 원하는 시야 폭(2~3mm)에서 초점이 맞는 거리를 찾습니다
2. 그 거리를 자로 잽니다
3. 그 길이의 통을 만들어 렌즈 앞에 붙입니다. 끝은 두피에 닿아도 아프지 않게 마감

### 4. 노출·화이트밸런스 고정

자동으로 두면 머리카락 양이나 두피 색에 따라 밝기가 흔들려서 **전후 비교가
안 됩니다.** 보드의 `rkipc.ini` 에서 자동 노출·자동 화이트밸런스를 끄고
값을 고정하세요.

```sh
./stream-tune.sh --show          # 현재 설정 확인
```

`[isp.0.adjustment]` 근처의 노출·화이트밸런스 항목을 찾아 수동으로 바꿉니다.
키 이름은 rkipc 버전마다 다르니 `--show` 출력에서 확인하세요.

## 화질 설정

세밀한 텍스처라 압축 손실이 눈에 띕니다. 관찰용으로는 비트레이트를 올리세요.

```sh
./stream-tune.sh --preset quality    # 2304x1296 / 6Mbps
```

움직임이 거의 없는 대상이라 프레임레이트는 낮아도 됩니다. 대신 비트레이트를
같은 값으로 두면 한 장당 화질이 올라갑니다.

## 앱에서

- **핀치 줌** — 두 손가락으로 확대, 끌어서 이동, **두 번 탭하면 원래대로**.
  화면에서 한 번 더 키워 보는 용도입니다(없는 정보를 만들지는 않습니다)
- **캡처** — 화면 크기가 아니라 **스트림 원본 해상도(2304×1296)** 로 저장됩니다.
  저장 후 안내 메시지에 실제 저장된 크기가 표시됩니다
- **갤러리** — 날짜순으로 쌓이므로 시간에 따른 변화를 비교할 수 있습니다.
  길게 눌러 시스템 갤러리로 내보내면 다른 앱에서도 볼 수 있습니다

같은 위치를 반복해서 찍으려면 두피에 기준점(가르마, 점 등)을 정해 두고
매번 같은 자리에서 찍는 게 좋습니다.
