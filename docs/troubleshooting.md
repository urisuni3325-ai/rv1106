# 문제 해결

## 앱에서 계속 "재연결 중"

증상별로 위에서부터 확인하세요.

1. **폰과 보드가 같은 공유기에 있는지.** 폰이 LTE/5G 로 빠져 있으면 절대 안 됩니다.
   폰 WiFi 설정에서 같은 AP 에 붙어 있는지 확인하세요.
2. **보드 IP 가 바뀌었는지.** DHCP 라 재부팅하면 바뀔 수 있습니다.
   보드에서 `./check-stream.sh` 로 현재 IP 를 확인하고 앱 설정을 고치세요.
   공유기에서 고정 할당을 걸어두면 다시 겪지 않습니다.
3. **스트리밍 서버가 떠 있는지.** `./check-stream.sh` 의 `rkipc` 와 554 포트 항목.
4. **PC 로 같은 주소가 열리는지.**
   ```sh
   ffplay -rtsp_transport tcp rtsp://<보드IP>:554/live/0
   ```
   PC 에서도 안 되면 앱 문제가 아닙니다. 보드/네트워크를 보세요.

앱 상태줄에 뜨는 메시지도 힌트가 됩니다.

| 메시지 | 뜻 |
|---|---|
| `Connection refused` | 그 IP 는 살아 있는데 554 포트에 서버가 없음 → rkipc 확인 |
| `connect timed out` | IP 까지 도달 못 함 → 다른 네트워크에 있거나 IP 가 틀림 |
| `DESCRIBE 실패 (404)` | 주소는 맞는데 경로가 틀림 → `/live/0`, `/live/1` 등 확인 |
| `인증 실패` | 아이디/비밀번호 → 앱 설정에서 입력 |
| `SDP 에서 H.264 비디오 트랙을 찾지 못했습니다` | 스트림이 H.265(HEVC)일 수 있음 (아래 참고) |

## 화면이 검은 채로 소리 없이 멈춰 있음

연결은 됐는데 첫 키프레임을 기다리는 상태입니다. GOP 가 크면 몇 초 걸립니다.

```sh
./stream-tune.sh --gop 25
```

## 화면이 녹색/깨진 블록으로 번짐

앱은 깨진 액세스 유닛을 버리도록 되어 있어서, 이 증상이 계속되면 보통 보드에서
나가는 스트림 자체나 무선 구간이 문제입니다. 비트레이트를 낮추고 보드를 공유기에
가까이 옮겨보세요.

## H.265(HEVC)로 설정돼 있는 경우

이 앱은 H.264 만 처리합니다. 보드 설정을 H.264 로 바꾸세요.

```sh
./stream-tune.sh --show          # output_data_type 값 확인
```

`output_data_type` 이 `H.265` 이면 `rkipc.ini` 에서 `H.264` 로 바꾸고 rkipc 를
재시작합니다.

## 녹화 버튼이 "준비 중"에서 안 넘어감

녹화는 키프레임에서 시작해야 재생이 깨지지 않기 때문에 첫 키프레임을 기다립니다.
GOP 길이만큼(보통 1~2초) 걸리고, 그보다 오래 걸리면 스트림이 실제로는 안 오고
있는 것입니다. 상태줄이 "스트리밍 중"인지 확인하세요.

## 녹화한 파일이 안 만들어짐 / 0바이트

저장할 프레임이 하나도 없으면 앱이 빈 파일을 지웁니다("저장된 프레임이 없어
파일을 만들지 않았습니다"). 연결이 실제로 붙은 상태에서 다시 시도하세요.

## 저장한 영상이 기본 갤러리 앱에 안 보임

앱 전용 폴더에 저장하기 때문입니다(저장소 권한을 요구하지 않으려는 설계).
앱의 갤러리 화면에서 항목을 **길게 눌러 → 갤러리로 내보내기** 를 선택하면
사진첩에서도 보입니다.

## 재생 중 앱이 뜨겁고 배터리가 빨리 닳음

- 해상도/비트레이트를 낮추세요(`docs/latency-tuning.md`).
- 녹화는 재인코딩을 하지 않으므로 발열의 원인이 아닙니다. 발열은 대부분 디코딩과
  화면 밝기입니다.

## wifi-setup.sh 가 "접속하지 못했습니다" 로 끝남

스크립트가 주변 공유기 목록과 함께 원인을 짚어 줍니다. 세 가지로 갈립니다.

**목록에 내 공유기가 보이고 보안에 `SAE` 가 없다** — 비밀번호입니다.
공유기 밑면 스티커에서 `0`(영)과 `O`, `1`(일)과 `l` 을 특히 확인하세요.

**보안 표시에 `SAE` 가 있다** — WPA3 가 켜져 있습니다. 비밀번호가 맞아도 붙지
않을 수 있으니 공유기 설정에서 보안을 **WPA2 전용**으로 바꾸세요.

**목록에 내 공유기가 없다** — 이름 철자(대소문자 구분)를 확인하고, 목록의 주파수
열에 5000번대가 하나도 없다면 이 보드는 2.4GHz 전용이므로 2.4GHz 쪽 이름을
써야 합니다. 보드를 공유기 가까이 옮겨 보는 것도 방법입니다.

**목록이 아예 비어 있다** — 드라이버 문제입니다.

```sh
dmesg | tail -30
```

## 보드가 부팅 후 WiFi 에 안 붙음

```sh
/etc/init.d/S80wifi restart
cat /etc/wpa_supplicant.conf
wpa_cli -i wlan0 status
```

`wpa_state=COMPLETED` 가 아니면 비밀번호나 SSID 문제입니다.
`wifi-setup.sh` 를 다시 실행하세요.
